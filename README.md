# Text Summarizer App

A lightweight text summarizer built with **Hugging Face Transformers** and **Gradio**, deployed on **Hugging Face Spaces**.

### Features

* Input any text and get a concise summary
* Powered by `facebook/bart-large-cnn`
* Clean UI with Gradio
* Easy to deploy and share

### Tech Stack

* Python
* Hugging Face Transformers
* Gradio
* Hugging Face Spaces

👉 Live Demo:  `https://huggingface.co/spaces/Chetankumawat/text_summizer`
